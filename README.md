# 🚨 The Midnight Alert
**Live Project Link** : https://somyagarg8877.github.io/The-Midnight-Alert/ 
### Emergency SOS & Personal Safety Web Application

The Midnight Alert is a web-based personal safety application designed to provide quick access to emergency assistance through an interactive SOS interface.

## 🎯 Project Overview

The application provides an emergency assistance interface with location tracking, trusted emergency contacts, alert history, and quick emergency calling options.

## ✨ Key Features

* 🚨 SOS Emergency Button with 5-second countdown
* 📍 GPS-Based Location Detection
* 👥 Trusted Emergency Contact Management
* 🗺️ Live Radar and Location Tracking
* 📜 Emergency Alert History
* 🔊 Emergency Siren
* 📞 Quick Emergency Calling
* 💬 WhatsApp and SMS Alert Sharing

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Geolocation API
* Web Audio API
* Local Storage
* Google Maps Integration

## ⚙️ Installation and Setup

1. Clone this repository:

   `git clone https://github.com/USERNAME/The-Midnight-Alert.git`

2. Open the project folder.

3. Launch `index.html` using a browser or a local development server.

4. Allow location permissions to test GPS functionality.

## 🔐 Privacy and Safety

The application uses browser-based location services and local storage for contact and alert history management.

Emergency sharing actions require user interaction.

## ⚠️ Disclaimer

This project is an academic prototype. It does not provide guaranteed automatic emergency notification delivery. Actual emergency communication depends on device, browser, network, permissions, and user confirmation.
